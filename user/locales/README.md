# Workshop 页面语言配置

- `zh-CN.json`：简体中文
- `zh-TW.json`：繁体中文
- `en.json`：英文

各文件使用相同的 `messages` 键。键是原始简体文案，值是该语言实际显示的文案。修改值即可调整对应语言；保留键不变。文件名、命令、产品名和技术标识应保持准确。页面从本机启动器按所选语言加载对应 JSON，语言选择会保存在浏览器本地，不保存账号密码。

新增页面文案时，给静态文本元素添加 `data-i18n="原始文案"`；动态 JavaScript 使用 `t("原始文案")`，并在三个文件里添加同名键。属性使用 `data-i18n-placeholder`、`data-i18n-alt` 等。截图不自动翻译；安装脚本和服务器的原始诊断日志保留原文。

请通过启动器打开页面，浏览器直接打开 HTML 文件时可能不允许加载本地 JSON。修改配置后刷新页面即可；首次增加本机服务允许的语言文件需重启启动器。
